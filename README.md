# 🌱 ชื้นอ๊ะยังจ๊ะ (Eart Plus)

ระบบรดน้ำต้นไม้อัตโนมัติด้วย **ESP32** สำหรับตรวจวัดความชื้นในดิน ควบคุมปั๊มน้ำอัตโนมัติ และสามารถตรวจสอบและควบคุมระบบผ่านโทรศัพท์มือถือแบบ Real-time

---

## 👥 สมาชิกในโครงงาน

1. **นางสาวอุษา อุปายโกศล**  
   รหัสนักศึกษา: `6730300671`

2. **นางสาวปิยดารัตน์ สุพินิจ**  
   รหัสนักศึกษา: `6730301031`

3. **นางสาวภูริชชยาพัชร์ สุพรรณ์**  
   รหัสนักศึกษา: `6730301066`

## 📌 รายละเอียดโครงงาน

**ชื้นอ๊ะยังจ๊ะ (Eart Plus)** เป็นระบบรดน้ำต้นไม้อัตโนมัติที่พัฒนาด้วย **ESP32** โดยระบบจะตรวจวัดค่าความชื้นในดินและนำค่าที่ได้มาใช้ในการควบคุมปั๊มน้ำ

ระบบสามารถทำงานได้ทั้งแบบ **อัตโนมัติ (Auto Mode)** และ **ควบคุมด้วยตนเอง (Manual Mode)** ผ่านสวิตช์ที่ติดตั้งบนอุปกรณ์ รวมถึงสามารถเชื่อมต่อกับโทรศัพท์มือถือผ่าน Wi-Fi เพื่อดูค่าความชื้นในดินและอุณหภูมิอากาศแบบ Real-time และสามารถสั่งเปิด-ปิดปั๊มน้ำจากโทรศัพท์ได้

---

## 🎯 วัตถุประสงค์

- ตรวจวัดค่าความชื้นในดิน
- ตรวจวัดอุณหภูมิของอากาศ
- ควบคุมการรดน้ำต้นไม้อัตโนมัติ
- แสดงค่าความชื้นและอุณหภูมิผ่านจอ LCD
- สามารถควบคุมระบบผ่านสวิตช์
- สามารถดูข้อมูลผ่านโทรศัพท์มือถือ
- สามารถสั่งเปิดและหยุดปั๊มน้ำผ่านโทรศัพท์
- ลดปัญหาการรดน้ำมากหรือน้อยเกินไป

## ⚙️ หลักการทำงาน

ระบบจะอ่านค่าความชื้นจาก **Soil Moisture Sensor** แล้วนำค่าที่ได้มาเปรียบเทียบกับค่าที่กำหนดไว้

| ความชื้นในดิน | สถานะดิน | การทำงาน |
|---|---|---|
| `≤ 35%` | 🌵 ดินแห้ง | เปิดปั๊มน้ำ |
| `36% - 59%` | 💧 อยู่ระหว่างช่วงกำหนด | คงสถานะปั๊มเดิม |
| `≥ 60%` | 🌱 ดินชื้น | ปิดปั๊มน้ำ |

### การทำงานแบบ Auto

```text
เริ่มต้น
   │
   ▼
อ่านค่าความชื้นในดิน
   │
   ▼
ความชื้น ≤ 35% ?
   │
   ├── ใช่ ──► เปิดปั๊มน้ำ
   │
   └── ไม่ใช่
          │
          ▼
     ความชื้น ≥ 60% ?
          │
          ├── ใช่ ──► ปิดปั๊มน้ำ
          │
          └── ไม่ใช่
                  │
                  ▼
             คงสถานะเดิม
```

การกำหนดค่าที่ 35% และ 60% ช่วยสร้างช่วง Hysteresis เพื่อป้องกันไม่ให้ปั๊มน้ำเปิดและปิดบ่อยเกินไปเมื่อค่าความชื้นอยู่ใกล้จุดเปลี่ยน

## 🎛️ การทำงานของสวิตช์

ระบบมีสวิตช์ทั้งหมด 3 ตัว

### 🔘 Switch 1 — Auto Mode

เมื่อกด Switch 1 ระบบจะเข้าสู่โหมดอัตโนมัติ

ESP32 จะตรวจสอบค่าความชื้นและควบคุมปั๊มน้ำตามเงื่อนไขที่กำหนด

```text
ความชื้น ≤ 35%
       ↓
   ปั๊มทำงาน

ความชื้น ≥ 60%
       ↓
   ปั๊มหยุด
```

---

### 🔘 Switch 2 — Manual Water ON

เมื่อกด Switch 2 ระบบจะเข้าสู่โหมด Manual และสั่งให้ปั๊มน้ำทำงานทันที

```text
กด Switch 2
     ↓
Manual Mode
     ↓
Pump ON
     ↓
เริ่มรดน้ำ
```

---

### 🔘 Switch 3 — Manual Water OFF

เมื่อกด Switch 3 ระบบจะสั่งให้ปั๊มน้ำหยุดทำงาน

```text
กด Switch 3
     ↓
Pump OFF
     ↓
หยุดรดน้ำ
```

---

## 📱 การเชื่อมต่อโทรศัพท์

ESP32 สามารถเชื่อมต่อกับ Wi-Fi และเปิดหน้าเว็บไซต์สำหรับตรวจสอบและควบคุมระบบ

ผู้ใช้งานสามารถเปิดเว็บไซต์จากโทรศัพท์ที่เชื่อมต่อ Wi-Fi เดียวกับ ESP32

หน้าเว็บไซต์สามารถแสดงข้อมูลแบบ Real-time ได้แก่

- 🌡️ อุณหภูมิอากาศ
- 🌱 ความชื้นในดิน
- 💧 สถานะปั๊มน้ำ
- ⚙️ สถานะ Auto / Manual

---

## 📲 การควบคุมผ่านโทรศัพท์

ผู้ใช้งานสามารถควบคุมระบบผ่านหน้าเว็บไซต์ได้

### Auto ON

เปิดระบบอัตโนมัติ

```text
Auto ON
   ↓
ESP32 ตรวจสอบความชื้น
   ↓
≤ 35% → Pump ON
≥ 60% → Pump OFF
```

### Auto OFF

ปิดระบบอัตโนมัติ

### Pump ON

สั่งเปิดปั๊มน้ำจากโทรศัพท์

### Pump OFF

สั่งหยุดปั๊มน้ำจากโทรศัพท์

---

## 🖥️ การแสดงผลบน LCD

ระบบใช้จอ LCD ขนาด **16×2 I2C** เพื่อแสดงข้อมูลปัจจุบัน

ตัวอย่างการแสดงผล

```text
T:28.5°C P:ON
Soil:32% Auto
```

ความหมาย:

- `T` = อุณหภูมิอากาศ
- `Soil` = ความชื้นในดิน
- `P:ON` = ปั๊มน้ำทำงาน
- `P:OFF` = ปั๊มน้ำหยุด
- `Auto` = โหมดอัตโนมัติ
- `Man` = โหมด Manual

## 🔌 อุปกรณ์ที่ใช้

| อุปกรณ์ | หน้าที่ |
|---|---|
| ESP32 | ควบคุมระบบทั้งหมด |
| Soil Moisture Sensor | วัดความชื้นในดิน |
| DHT22 | วัดอุณหภูมิอากาศ |
| Relay Module | ควบคุมปั๊มน้ำ |
| Water Pump | รดน้ำต้นไม้ |
| LCD 16×2 I2C | แสดงข้อมูล |
| Switch 1 | เลือก Auto Mode |
| Switch 2 | สั่งเปิดปั๊ม |
| Switch 3 | สั่งปิดปั๊ม |
| Wi-Fi | เชื่อมต่อโทรศัพท์กับ ESP32 |

---

## 🔧 การกำหนด GPIO

| อุปกรณ์ | ESP32 GPIO |
|---|---:|
| Soil Moisture Sensor | GPIO 34 |
| DHT22 | GPIO 27 |
| Relay / Pump | GPIO 26 |
| Switch 1 | GPIO 14 |
| Switch 2 | GPIO 12 |
| Switch 3 | GPIO 13 |
| LCD SDA | SDA |
| LCD SCL | SCL |

> **หมายเหตุ:** การเชื่อมต่อ Relay ควรตรวจสอบว่า Relay Module ที่ใช้งานเป็น Active HIGH หรือ Active LOW เนื่องจากแต่ละรุ่นอาจมีการทำงานแตกต่างกัน

## 🌐 การสื่อสารแบบ Real-time

ระบบใช้ **WebSocket** สำหรับส่งข้อมูลระหว่าง ESP32 และโทรศัพท์

ตัวอย่างข้อมูลที่ส่ง:

```json
{
  "temp": 28.5,
  "soil": 32,
  "pump": 1,
  "auto": 1
}
```

ความหมายของข้อมูล:

| ตัวแปร | ความหมาย |
|---|---|
| `temp` | อุณหภูมิอากาศ |
| `soil` | ความชื้นในดิน |
| `pump` | สถานะปั๊มน้ำ |
| `auto` | สถานะ Auto Mode |

## 🧠 Logic การควบคุม

ระบบ Auto ใช้เงื่อนไขดังนี้

```cpp
if (soil <= 35) {
    setPump(true);
}
else if (soil >= 60) {
    setPump(false);
}
```

ดังนั้น

```text
Soil ≤ 35%
     ↓
เปิดปั๊ม

Soil ≥ 60%
     ↓
ปิดปั๊ม

Soil 36-59%
     ↓
คงสถานะเดิม
```
